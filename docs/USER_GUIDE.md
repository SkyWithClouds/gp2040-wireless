# 玩家使用指南

你要做的是给手柄加一个外置无线转接盒。贴两张标签最省事：把手柄旁的 NOLOGO 标成 **#1 发射**，插电脑的那块标成 **#2 接收**。两块板外观相同，固件不同。

阶段 1 已通过 Windows 实板验收。阶段 2 和阶段 3 的云端固件构建已通过，等待实板验收。建议先测两块 NOLOGO，再接 Pico 和真手柄。

## 阶段 1 · 只试电脑旁的接收板

单独使用 **#2 接收板** 就能测试。先按下文的双复位步骤保存 `INFO_UF2.TXT`，按[开发指南](DEVELOPMENT.md)核对应用起址为 `0x26000`。芯片型号和 UF2 Family ID 相同仍可能对应不同的引导器布局。

打开 **Actions → Bridge CI** 中成功的手动 `xinput` 运行，从 Artifacts 下载 `usb-rx-xinput-<提交号>`，解压并将其中的 `usb-rx-xinput-nologo-26000.uf2` 拖入 #2 引导盘。重启后用 USB 数据线接 Windows 10/11。在 `joy.cpl` 选择新控制器，打开“属性 → 测试”。每步约 1 秒，每 8 秒重复一圈：

| 秒 | 预计看到 |
|---|---|
| 0 | 所有输入中立 |
| 1、2 | A；随后 A+B 同时按住 |
| 3 | 方向帽向右 |
| 4、5 | 左、右扳机依次按满（有些界面表现为同一轴的两个方向） |
| 6 | 两根摇杆移向相反的对角方向 |
| 7 | 最近的 1P、2P、3P、4P 灯命令分别显示为 A、B、X、Y；尚未分配或收到灭灯命令时中立 |

第 7 秒的反馈用于验收接收板的 USB OUT。

## 阶段 2 · 两块板直接试无线

1. 从同一次成功的 **Actions → Bridge CI → 手动 esb 构建 → Artifacts** 下载两个压缩包。给两块板贴标签。刷机时每次只接一块，断开电池和其他电源，双击复位，将对应 UF2 拖进引导盘。
2. 给 **#2 接收** 刷 `02-receiver-esb-nologo-26000.uf2`，用数据线接 Windows，打开 `joy.cpl` 的手柄属性。此时所有按键应松开。
3. 给 **#1 发射** 刷 `01-transmitter-esb-nologo-26000.uf2`，接常开 USB 电源。两块板之间无需接线，也无需接 Pico 或 Hitbox。输入序列由 #1 产生。两块板通电后等待一个完整周期。

| 从 #1 启动起，每 8 秒重复 | 应看到的输入 |
|---|---|
| 第 0–1 秒 | 中立 |
| 第 1–3 秒 | 持续按住 A，便于测试断电释放 |
| 第 3–4 秒 | 同时按住 A+B |
| 第 4–6 秒 | 中立，第 5 秒插入 A → A+B → B → 全松，前三步各持续 4 ms |
| 第 6–7 秒 | 十字键右 |
| 第 7–8 秒 | #1 根据无线收到的玩家灯命令送回按键。1P/2P/3P/4P 分别显示 A/B/X/Y，灭灯或未分配时中立 |

在 A 长按时只拔 **#1 的电源**。#2 应留在 Windows 设备列表中且按键释放，重接 #1 后从当前状态继续。肉眼适合看长按、断线和灯号。4 ms 连按的顺序及 50 ms 的计时需要抓包核对，详见[开发验收步骤](DEVELOPMENT.md)。

## 准备硬件

| 物品 | 数量 | 用途 |
|---|---:|---|
| 成品 GP2040-CE Hitbox 和原装 USB 数据线 | 1 套 | 提供手柄输入 |
| 官方 Raspberry Pi Pico（RP2040，原版）和 Micro-USB 数据线 | 各 1 | 读取手柄，给 Pico 供电和刷机 |
| 无名科技 NOLOGO ProMicro nRF52840 | 2 | 分别做发射端和接收端，准备相应的 Type-C 数据线 |
| 带标记的 USB-A 母座转接板 | 1 | 接 Hitbox 的原装线 |
| 短连接线、22 Ω 电阻 | 若干线、2 只电阻 | 连接排针，两根 USB 数据线各串一个电阻 |
| 5 V 充电宝 | 1 | 首次联调推荐用能同时给 Pico 和 #1 的 USB 口供电的型号 |
| 单节受保护的 18650、电池座及有保护的稳压 5 V 升压供电组件 | 电池方案选配 | 可代替充电宝。首次装机可跳过电池方案 |

## 先用原装线确认手柄模式

1. 拔下 Hitbox。按住原板的 **B2**（默认映射为 Xbox 的 **B**），把原装线直接插入电脑，等设备被识别后松手。这是 GP2040-CE 默认的 XInput 启动方式。
2. 在 Windows 按 `Win + R`，输入 `joy.cpl` 并回车。选中控制器，打开“属性”，试按方向和两个常用键，记住直连时的表现。
3. 成品面板的印字可能是拳脚键。B2 位置或启动快捷键被改过时，查该手柄说明，或用原板有线 Web 配置器核对输入模式设置。接入外挂时也要让原板以 XInput 启动。[GP2040-CE 按键映射与启动模式](https://gp2040-ce.info/usage/)

## 断电接线

**先拔掉电脑 USB、充电宝和电池。** Pico 表中“Pin”是物理脚号，“GP”是电路名称。先按板子正反面和丝印辨方向，USB 母座的焊接面与插口面可能左右相反，以转接板的标记为准。

### 第一步 · USB-A 母座接 Pico

| USB-A 母座 | Pico 物理脚 | 接法 |
|---|---|---|
| D+ | **Pin 1 · GP0** | 中间串 22 Ω |
| D− | **Pin 2 · GP1** | 中间串 22 Ω |
| GND | Pin 3 · GND | 接地 |
| VBUS / 5V | Pin 40 · VBUS | 充电宝接 Pico Micro-USB 时，从这里给母座供 5 V |

Hitbox 的原装线插在这个母座上。Pico 自带的 Micro-USB 口留给供电、刷机或调试。

### 第二步 · Pico 接 #1 发射板

按 NOLOGO 原理图的**左侧排针 NP1** 找脚，先核对丝印，再数排针。表中六根线全部接上。

| Pico 物理脚 | NOLOGO #1 丝印 | NP1 排针脚 | 用途 |
|---|---|---|---|
| Pin 24 · GP18 | 020 · P0.20 | 7 | SCK，时钟 |
| Pin 25 · GP19 | 017 · P0.17 | 6 | MOSI，Pico 送按键 |
| Pin 21 · GP16 | 022 · P0.22 | 8 | MISO，发射板回状态 |
| Pin 22 · GP17 | 024 · P0.24 | 9 | CS，选择发射板 |
| Pin 26 · GP20 | 100 · P1.00 | 10 | READY，发射板准备好了 |
| Pin 23 · GND | GND | 4 或 5 | 两块板共地 |

**#2 接收板不用接这些线**，使用时直接用 Type-C 数据线插 Windows 电脑。

### 第三步 · 核对供电再上电

- **严禁把 5 V 接到任一 NOLOGO 的 `BAT` 或 GPIO。** 初次装机让充电宝分别通过 Pico 的 Micro-USB 和 #1 的 Type-C 口供电；两板之间只接上表信号和地线。
- **刷任何一块板前，断开充电宝、18650 和其他供电线。** 将待刷的板单独连电脑。外部 5 V 和电脑的 USB 5 V 接在一起可能互相倒灌。
- 使用 18650 时，让有保护的升压组件输出稳定 5 V 后再给 USB 端供电。**单节电池不得直接接 USB-A 的 VBUS。** 若用独立稳压 5 V 给母座供电，断开母座到 Pico Pin 40 的 5 V 连线，并共地。
- 首次插上 Hitbox 前，用万用表确认母座 VBUS 对 GND 约为正 5 V、两条数据线没有接到 5 V。遇到板子发烫或电源反复保护，立即断电检查。

## 阶段 3 · 完整链路刷机

在 **Actions → Bridge CI** 打开一次成功的手动 `full` 运行，从 **Artifacts** 下载同一提交的三个压缩包并解压。以下 01、02、03 是文件编号。两块 NOLOGO 上的 #1 发射、#2 接收标签继续按原来的角色使用。

| 压缩包 | 解压后文件 | 刷到 |
|---|---|---|
| `pico-host-full-…` | `01-pico-host-full.uf2` | 官方 Pico（RP2040） |
| `radio-tx-full-…` | `02-transmitter-full.uf2` | 手柄侧 NOLOGO #1 |
| `usb-rx-full-…` | `03-receiver-full.uf2` | 电脑侧 NOLOGO #2 |

刷机前断开外部电源和板间接线。Pico 按住 **BOOTSEL** 插电脑，出现 **RPI-RP2** 盘后松手并拖入 Pico 固件。两块 NOLOGO 逐块用 USB 数据线连电脑，快速复位两次，确认引导盘后拖入对应 UF2。每块都等复制完成、板子自动重启，再断电接回线路。

## 实板验收清单

- [ ] **阶段 2，先测无线。** #2 刷接收测试固件，单独插 Windows，`joy.cpl` 应显示手柄且输入中立。#1 刷发射测试固件，只接 USB 电源。每 8 秒重复一圈，可见 A 长按、A+B、方向右和最后一秒的玩家灯反馈。1P 应显示 A。
- [ ] **阶段 2，测断电。** 在 A 长按时只断 #1 的电。Windows 手柄仍在，A 应释放。重启 #1 后应恢复当前测试状态。要核对 4 ms 点按、双键同包与 50 ms 判定时间，按开发指南抓包。
- [ ] **阶段 3，刷三板、断电接线。** Pico 刷 01，#1 刷 02，#2 刷 03。核对 GP0=D+、GP1=D−、SPI 五线和共地。严禁 5 V 接 NOLOGO 的 BAT 或 GPIO。先确认 Hitbox 有线直连时能以 XInput 工作。
- [ ] **阶段 3，核对原板手感。** #2 插 Windows，Hitbox 以 XInput 模式接 Pico，再给手柄侧供电。把极速点按、长按蓄力 60 秒、双键同时按、原板快捷键切方向帽或摇杆逐项与有线基准比较。正式固件空闲时手柄应保持中立。
- [ ] **阶段 3，拔插与恢复。** 按住 A 时先只拔 Hitbox，观察清零。断开期间做一次已结束的动作，重连时保持另一个键，确认恢复当前按键。再单独给 #1 断电复测，观察有无卡键或延迟补招。
- [ ] **阶段 3，核对玩家灯。** 用 Pico 原生 Micro-USB 数据线接电脑供电，打开其 USB 串口。Windows 发灯命令后，查看 `led_out` 增加、`applied=1`、`applied_gen=gen`，并记录 `mode`。有玩家灯的 Hitbox 可同时核对灯效。保存固件提交号、日志及异常发生时的操作。

## 遇到问题先查哪里

| 现象 | 先做这一步 |
|---|---|
| Actions 页面没有三个下载项 | 核对阶段是否为 `full`、是否有三个成功的构建任务、产物是否已过期。 |
| 板亮着，电脑没有刷机磁盘 | 换已知能传数据的线，拔下另一块板，重做 BOOTSEL 或双复位；普通运行模式不会持续显示磁盘。 |
| 接收板插上，Windows 看不到手柄 | 核对是否误刷了 #1 的固件；用数据线直插电脑，查看设备管理器，再用 `joy.cpl` 检查。 |
| Windows 有手柄，按键没反应 | 阶段 2 确认 #1 已供电。阶段 3 看 Pico 串口，pad=0 先查 Hitbox 模式、母座 5 V 和 D+/D−；pad=1 但 active=0 时查 SPI 共地、READY、两板供电和接收板连接。 |
| 开机一会儿整套熄灭 | 充电宝可能因负载太轻而关机。开启其“小电流常开”模式，或换稳定的 5 V USB 电源。 |
| 手柄能用，玩家灯没亮 | 看原板直连时是否有玩家灯、主机是否分配了灯号；有些成品没有对应灯。改键或进 Web 配置器时请直连原板。 |
